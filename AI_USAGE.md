# AI Usage

AI assistance was used for architecture brainstorming, implementation scaffolding, UI iteration and adversarial test-case ideation.

Human review remains responsible for:
- security and authorization decisions;
- server-authoritative timing and scoring;
- database constraints and data exposure;
- accessibility, Arabic/RTL behavior and responsive UX;
- dependency and configuration changes;
- running lint, typecheck, unit tests, E2E tests and a production build;
- clean-machine verification before submission.

No secrets or private credentials are intentionally included in the repository. Demo credentials are seed-only assessment data.
